FINAL PROJECT SETUP

1. Java
- This project is configured for JDK 24.
- In IntelliJ: File -> Project Structure -> Project -> SDK: JDK 24.
- Language level: 24 (or SDK default).

2. MySQL
- Database: museum_db
- Host: localhost
- Port: 3306
- User: root
- Password used by the project: 200724

3. JDBC driver
- If MySQL Connector/J is already configured in IntelliJ, the application will read the exhibits and time_slots tables directly.
- If Connector/J is not available, the application automatically uses the included data/exhibits.txt and data/time_slots.txt fallback, so View Exhibits and booking still work.

4. Database time slots expected by the application
 time_slots(id, exhibit_id, slot_date, start_time, end_time, capacity, booked_tickets, status)

The booking screen now filters slots by the date entered by the visitor and asks the visitor to choose the slot for that date.
